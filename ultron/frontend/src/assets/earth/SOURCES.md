# Static Earth surface artwork

Bundled on 2026-10-15 from the Three.js example texture distribution:

- https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
- https://threejs.org/examples/textures/planets/earth_lights_2048.png
- https://threejs.org/examples/textures/planets/earth_clouds_1024.png

Source repository: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets
Three.js distribution license: MIT, https://github.com/mrdoob/three.js/blob/dev/LICENSE
Earth imagery is static reference artwork. It does not establish current cloud,
weather, city activity or live satellite observation. Re-encoded as WebP locally
for bounded loading and to avoid third-party texture requests at runtime.

The night-lake wallpaper in `public` and Cloud `static` was generated for GÖLGE
with the session image-generation tool. It is photorealistic illustration, not a
photograph of a known site or a live feed. No UI is embedded in the image.
